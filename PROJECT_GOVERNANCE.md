# 1. Vision du projet

ForeverCare AI est une plateforme intelligente de gestion, de suivi et d'accompagnement des clients utilisant les produits Forever Living.

L'objectif est de construire un logiciel professionnel, évolutif, sécurisé, performant et commercialisable, destiné à accompagner les distributeurs Forever dans la gestion de leurs clients, de leurs ventes et de leurs activités quotidiennes.

Le projet est développé avec une vision long terme et doit rester maintenable pendant de nombreuses années.

---

# 2. Valeurs du projet

Toutes les décisions techniques devront respecter les principes suivants :

* Simplicité
* Robustesse
* Évolutivité
* Lisibilité
* Réutilisabilité
* Performance
* Sécurité
* Documentation permanente
* Zéro régression

# 4. Cycle de développement

Chaque développement suit obligatoirement le cycle suivant :

1. Analyse.
2. Validation de l'architecture.
3. Vérification de l'existant.
4. Création des dossiers.
5. Création des fichiers.
6. Développement.
7. Compilation.
8. Tests.
9. Validation.
10. Documentation.
11. Clôture du sprint.

---

# 5. Règles officielles

Le projet applique les règles suivantes :

1. L'architecture est pilotée de manière centralisée.
2. Le chemin exact de chaque fichier est toujours indiqué.
3. Aucune régression n'est acceptée.
4. Aucun fichier existant n'est modifié sans analyse préalable.
5. Les impacts sont étudiés avant toute modification importante.
6. Le développement est organisé par sprints.
7. La documentation est maintenue en continu.
8. La qualité du code est prioritaire.
9. L'architecture validée ne change qu'après analyse.
10. Toutes les commandes sont fournies pour Windows CMD.
11. L'arborescence est vérifiée avant chaque sprint.
12. La documentation constitue une partie intégrante du projet.
13. Toute décision d'architecture suit un processus d'analyse et de validation.
14. Aucun sprint ne se termine sans compilation.
15. Toute duplication de code est évitée.
16. Les modules communiquent via des interfaces ou des services.
17. La logique métier reste en dehors des widgets.
18. Chaque module possède sa documentation.
19. La qualité prime toujours sur la vitesse.
20. ForeverCare AI est développé comme un produit logiciel commercial.
21. Aucune dette technique volontaire n'est acceptée.
22. Aucun code jetable n'est intégré au projet.
23. Aucun sprint ne commence sans check-list.
24. Le projet est auto-documenté.
25. Chaque sprint fait l'objet d'un audit qualité.

Chaque décision technique doit préparer l'avenir du projet sans complexifier inutilement le présent.
