# ForeverCare AI Development Standard

## Règle 1

Toujours partir des fichiers existants.

## Règle 2

Remplacer un fichier complet plutôt que coller des fragments.

## Règle 3

Ne jamais modifier un module validé sans nécessité.

## Règle 4

Architecture unique pour tous les modules.

## Règle 5

Validation obligatoire :

- flutter analyze
- flutter test
- flutter run

## Règle 6

Un module n'est terminé que lorsque :

- CRUD complet
- UI complète
- SQLite validée
- Navigation validée
- Dashboard connecté
