# Photos des élèves — points à faire vérifier

Photos d'enfants mineurs : à faire vérifier par un professionnel ou
l'autorité compétente au Burkina Faso (CIL) avant usage réel.

| # | Point | Ce que fait l'application |
|---|---|---|
| P1 | Consentement des parents pour la photo et la carte | Texte d'information proposé, imprimable (accepte / refuse) ; photo facultative |
| P2 | Qui peut voir les photos | Directeur, délégués « élèves », « registres », « cartes », l'enseignant(e) de la classe ; jamais d'autre classe ni d'autre école |
| P3 | Publication | Compartiment privé, aucun lien public (vérifié par les tests) |
| P4 | Durée de conservation ; suppression quand l'élève quitte l'école | **À définir** ; une photo remplacée est effacée du téléphone ; l'ancienne reste sur le serveur |
| P5 | QR code | Contient seulement un identifiant aléatoire, sans nom ni donnée personnelle |
| P6 | Impression chez un imprimeur extérieur | À encadrer (le PDF contient les photos) |
